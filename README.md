# Проект Виджет Банк

## Цель проекта создать  новую фичу для личного кабинета клиента, который показывает несколько последних успешных банковских операций клиента.

### В проекте реализованы функции:
### get_mask_card_number
    Маскирует номер банковской карты по шаблону «XXXX XX** **** XXXX».

### mask_account_card
    
    Обрабатывает информацию о банковских картах и счетах, возвращая строку с замаскированными данными.

### get_date
    
    Преобразует строку с датой из формата ISO в формат «ДД.ММ.ГГГГ»

### filter_by_state

    Фильтрует список словарей по значению ключа 'state'.

### sort_by_date

    Сортирует список словарей по дате (ключ 'date')
